### Design
- **Reference teardowns** (bo-teardown, one subagent each) are in `C:\Users\Client\LPT\nico-teardowns\` (outside the repo). Licences: Tajmirul/portfolio-2.0 MIT; HamishMW/portfolio MIT; Naresh-Khatri/3d-portfolio has no licence file (treated as all rights reserved). **No code, copy, images, 3D files or fonts from any of them are used**: patterns only. The footer credits all three anyway ("Inspired by the work of …"); `THIRD_PARTY_NOTICES.md` records the licences.
- **bo-rebuild was not used** (the brief forbids cloning); one original design blends: oversized name, real-number stat strip, dual CTAs, layered stack, hover-preview rows, email rail, GSAP + Lenis, no preloader (tajmirul); WebGL hero, rotating role, numbered case studies, accessible motion, light/dark (hamishw); an interactive 3D keyboard of the stack (nareshkhatri, rebuilt from scratch in React Three Fiber, no Spline).
- **The frontend-design skill isn't available in this environment**; the visual direction was set here and in the build briefs.
- **Clearly different from Ehjay's site:** midnight navy + electric blue/cyan (not lime on black), Sora / DM Sans / IBM Plex Mono (not his fonts, and not the references' fonts either), no split hero, no command palette.
- **Hero 3D:** an instanced "data skyline" (bars moving like live chart data), lazy-loaded after first paint and idle, only on ≥ 768px with motion allowed and WebGL available; otherwise a static SVG poster. The name (`<h1>`) is plain server HTML and the LCP element.
- **Keyboard:** rows are the stack layers (frontend, backend + database, data & integrations, tools). Pressing a key (or a button in the plain list) selects a tech in a tiny shared store (`lib/tech-store.ts`); the Used-in panel lists the projects, and the Selected work rows highlight them. Legends are drawn on a CanvasTexture (no network fonts). Phones and reduced motion get a static poster; the plain list is the accessible control everywhere.
- **Theme:** dark by default, light on request, stored in `localStorage` and applied before paint by a tiny inline script (no flash). Without JavaScript the site is dark and fully readable; reveal animations only hide content when JS runs.

### Engineering
- Next.js 16.3.8, React 19.2.8, TypeScript 6.0.3, Tailwind CSS 4, pnpm 12.9.1: Ehjay's versions. Added (approved): three, @react-three/fiber, @react-three/drei, gsap, @gsap/react, lenis; dev: playwright, @axe-core/playwright, lighthouse, sharp. zod is used only on the server (contact action), so it doesn't ship to visitors. No MDX/content-collections: case studies are typed data in `content/projects.ts`.
- **Security headers** (all routes except `/demos/*`): CSP same-origin only (`'unsafe-inline'` scripts are needed for Next's inline bootstrap on a static site without per-request nonces), `frame-ancestors 'self'`, X-Frame-Options SAMEORIGIN, nosniff, strict Referrer-Policy, Permissions-Policy, HSTS, COOP. The demos keep their own headers (noindex + ACAO for their fonts in the sandboxed iframe).
- **Memory:** this PC has under 0.5 GB free. Builds use `CIRCLE_NODE_TOTAL=3`; the build agents were told not to run builds or type checks in parallel.
- **Vercel:** new project `nicoagustin` (scope agustinnico228-2616) created with `vercel link --project nicoagustin`; `ENABLE_EXPERIMENTAL_COREPACK=1` set for Production and Preview. The `ehjay-lorenzo` project is untouched.

### After the first deploy (02:56)
- **First production deploy** at 02:56: https://nicoagustin.vercel.app. Screenshots at 320–1920 (home + a case study): no console errors, failed or third-party requests, 4xx/5xx or horizontal overflow.
- **CSS layers:** the shared classes (`.btn`, `.chip`, `.container-x`…) moved into `@layer components` and the element defaults (`a`, `img`, `:focus-visible`…) into `@layer base`, so Tailwind utilities (`hidden`, `text-accent`, `rounded-*`) override them as expected. Unlayered CSS beats every layer regardless of specificity.
- **Hero:** the 3D bars ran under the stat strip at 1440. The visual box now fades out above the stats (`.hero-visual-mask`, two intersected masks) and the camera aims lower so the skyline sits higher in the frame.
- **Rotating role:** the pause button keeps one accessible name ("Pause the role animation") with `aria-pressed`, instead of a label that flips; it has a visible ring so it reads as a control (WCAG 2.2.2 pause for auto-moving content).
- **GitHub security:** secret scanning and push protection (already on), Dependabot alerts and Dependabot security updates enabled, CodeQL default setup configured. `pnpm audit --prod`: no known vulnerabilities; the one advisory is in a dev-only lint dependency (braces via eslint-config-next) with no patched version yet.
- **JSON-LD escaping:** U+2028/U+2029 are escaped with char codes in `lib/jsonld.ts` (a raw separator inside a regex literal is a syntax error, and tool-written `\u` escapes were decoded into raw characters).

### QA round 1 (03:00–03:30): measure once, review through five lenses
- **Measured on the live site** (one agent, sequential to spare RAM): 8 routes × 9 widths (320–1920) with no overflow, console errors, failed/third-party requests or 4xx/5xx; axe (390 + 1440, dark + light) 0 serious/critical, 16 moderate `region` hits from the email rail (fixed: it is an `<aside>` landmark now); Lighthouse home mobile 79 → **95** after the performance fixes (TBT 657 → 157 ms), desktop 99–100, Accessibility / Best Practices / SEO 100 everywhere.
- **Performance:** the 1.3 s of style and layout on a throttled phone came from laying out the whole long page at load. Below-the-fold sections (Stack, Experience, Certificates, Contact, footer) use `content-visibility: auto` with intrinsic sizes; Selected work does not (its fixed hover preview must not be trapped by containment). Lenis and GSAP load lazily.
- **Campaign attribution (blocker):** Nico's part in the Rooming House Expert campaign is not recorded, so nothing may imply it. The hero stat "257 leads" was replaced by "4 websites and portals built"; the keyboard no longer maps Meta Ads/Excel to the campaign (Excel now points to his MOS Excel certification; Meta Ads still maps to the dashboards, which read Meta data); JSON-LD names Nico as `creator` only for projects with a recorded role; the résumé lists the campaign without its results. The case study still shows the client-approved results (the brief asked for them), with no role.
- **"Full-time" removed:** no source says the Agora Data Driven job was full-time; the stat and résumé say "as a fullstack developer at Agora Data Driven" / "One year as a Fullstack Web Developer at Agora Data Driven".

### QA round 2 and wrap-up (03:45–04:10)
- **Measurement fidelity:** the QA harness now reveals every `[data-reveal]` element, waits for the fade to finish and renders `content-visibility` sections before running axe/screenshots. axe had flagged certificate cards captured mid-fade (opacity 0.94) and, once, cards it couldn't lay out because the browser was skipping the off-screen section; both pass in their real rendered state (verified separately by scrolling like a visitor).
- **Keyboard legends** use IBM Plex Mono 600 (added to next/font; it is not preloaded and downloads only when the 3D scene draws its legends).
- **Copy originality:** after the rewrite, the closest sentence to Ehjay's text scores 0.72 (a list of HydRate's treatments, proper nouns) and only two sentences score ≥ 0.6, both proper-noun lists (was 116 sentences ≥ 0.6, max 1.00).
- **Apps Script limits** (20 emails per clock hour, a 10-email quota floor, 10-minute duplicate check, one request at a time) take effect only after the script is installed or updated (Manage deployments → Edit → New version).
